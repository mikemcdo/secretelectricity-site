TypeLock for Jira

Restrict who may create a specific work item type, by group or project role — enforced on the workflow, not hidden in the interface.

How these apps are built

Every app here runs entirely on Atlassian Forge, inside Atlassian's own infrastructure. There is no external server, no database of ours, and no third-party service in the path. Your data does not leave Atlassian.

Apps request the smallest set of permissions they can work with, and prefer read-only access wherever the job allows it. Where an app enforces a rule, it does so server-side, so the rule holds whether the work item is created through the Jira interface, the REST API, or automation.
